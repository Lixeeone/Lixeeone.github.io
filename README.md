# GitHub Pages — 3D Under Construction

这是增强版的纯静态 GitHub Pages「施工中」首页。

### 技术
- Three.js WebGL
- UnrealBloomPass 泛光
- 3D 建筑施工框架
- 动态几何模块
- 发光能量环
- 900 粒子星尘
- 鼠标视差 / 相机跟随
- CSS 液态 Aurora 光效
- 入场遮罩 + 标题级动画
- 响应式移动端

### 部署
把 `index.html`、`style.css`、`script.js` 放到 GitHub Pages 仓库根目录即可。

本项目使用 jsDelivr CDN 加载 Three.js，因此无需 npm、无需构建。
